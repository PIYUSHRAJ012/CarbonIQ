# CarbonIQ

An Intelligent Carbon Footprint Analytics and Sustainability Decision Support Platform.

## Tech Stack

- Django
- PostgreSQL
- Pandas
- NumPy
- Scikit-Learn
- Plotly
- Bootstrap
- Docker
- AWS EC2

## Features

- Carbon Footprint Calculator
- ML Prediction
- User Segmentation
- Recommendation Engine
- Interactive Dashboard
- Eco Score
- Gamification
